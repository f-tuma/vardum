# Security Policy

## Supported versions

The latest `0.1.x` release receives security fixes. Upgrade to the newest patch
release before reporting an issue.

## Reporting a vulnerability

Report vulnerabilities privately through the repository's **Security** tab by
opening a GitHub private vulnerability report. Do not open a public issue with
exploit details, credentials or customer data.

Include the affected version, deployment configuration, reproduction steps and
impact. Maintainers will acknowledge the report through GitHub and coordinate a
fix and disclosure there.
