# Security Policy

## Supported versions

Security fixes target the current source and latest published clients. The
current documented clients are CLI `0.8.3`, MCP `0.4.2` and shared `0.4.2`;
see the [release and compatibility table](docs/npm-release.md) for updates.
Older client or server versions may need an upgrade to receive a fix.

## Reporting a vulnerability

Report vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/f-tuma/vardum/security/advisories/new).
If the report form is unavailable, open an issue asking only for a private
security contact. Do not include exploit details, credentials or customer data
in that issue.

Include the affected client version or source commit, deployment configuration,
reproduction steps and impact. Use the private report to coordinate a fix and
disclosure with the maintainers.
